# Elij UI Library CLI

CLI for discovering components from `elij-ui-library`.

## Install

```bash
npm install elij-ui-library-cli
```

## Usage

The short command is recommended:

```bash
elij-ui list
elij-ui search button
elij-ui info Button
elij-ui doctor
```

For naming consistency, the same CLI is also available as:

```bash
elij-ui-library list
elij-ui-library-cli list
```
