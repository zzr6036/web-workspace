# Changelog

All notable changes to elij-ui-library are documented here.

## [Unreleased]

- Keep the component registry and Storybook catalog aligned with public exports.
- Prepare the registry for the future Elij UI CLI and MCP server.

## [1.0.0] - 2026-09-11

- Declared the React component API, registry schema, CLI commands, and MCP tools stable.
- Synchronized `elij-ui-library`, `elij-ui-library-cli`, and `elij-ui-library-mcp` at the first stable release.
- Verified build, typecheck, lint, unit tests, and MCP protocol tests before release preparation.

## [0.1.0] - 2026-09-07

- Published the first public npm release.
- Added reusable React components, styles, TypeScript declarations, and Storybook examples.
- Added reusable EventCarousel, FilterTabs, SectionHeading, WhatsAppButton, and WhatsAppIcon exports.
